# Project Rules

- Keep code simple, reusable, and configuration-driven.
- Keep all code, comments, file names, and documentation in English.
- Use kebab-case for files and directories.
- Put user-facing text in `src/i18n/locales/en.json`.
- Use `twMerge` whenever Tailwind classes are composed conditionally.
- Never show ads on settings, authentication, dialogs, or empty dead-end pages.
- Use `display: none` for temporary ad-container suspension and `shutdown()` only
  when permanently removing an OwAd instance.
- Never commit or push without explicit approval.
